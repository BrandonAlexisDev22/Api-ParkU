Module: novedadModel

Modelo que representa una novedad registrada dentro del sistema de gestión de parqueaderos. Una novedad permite registrar situaciones o eventos que ocurren dentro del parqueadero, tales como: - Vehículo mal estacionado - Daños en una celda - Problemas de seguridad - Bloqueo de espacios - Reportes administrativos
