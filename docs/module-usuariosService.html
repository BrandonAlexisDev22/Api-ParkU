Module: usuariosService

Service encargado de manejar la lógica de negocio de los usuarios dentro de la arquitectura MVC. Responsabilidades: - Aplicar reglas de negocio - Validar datos antes de enviarlos al repositorio - Comunicarse con el Repository para acceder a la base de datos Flujo: Controller → Service → Repository → Base de Datos
